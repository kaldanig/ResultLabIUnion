# Code of conduct

This project follows the [Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).
It applies to everyone who takes part: in issues, pull requests, reviews, commit messages and anywhere else the
project is discussed.

## In short

- Be respectful and assume good intent. Disagree with ideas, not with people.
- Give and take criticism of code and documentation constructively, and accept that a decision may go the other way.
- No harassment, insults, personal or political attacks, sexualized language or imagery, and no publishing anyone's
  private information.
- Keep in mind that many contributors write in a language that is not their first.

The full text of the Contributor Covenant, linked above, is the standard; this summary does not replace it.

## Reporting

If someone's behavior in this project worries you, tell the maintainer privately. Do not describe it in a public
issue: open an issue titled **"Code of conduct: please contact me"**, with nothing else in it, and the maintainer will
reach you privately. You can also use the contact details on the maintainer's GitHub profile,
[@kaldanig](https://github.com/kaldanig), where they are listed.

Every report is read, kept confidential, and answered. The maintainer decides what to do, from a private word to a
public warning, a temporary ban or a permanent ban, following the Contributor Covenant's
[enforcement guidelines](https://www.contributor-covenant.org/version/2/1/code_of_conduct/#enforcement-guidelines).
Someone reported in good faith is never penalized for it.

Security vulnerabilities are not reported here: see [SECURITY.md](SECURITY.md).
